# Assets

Every image or code file a journal uses lives here, so the log is self-contained and no journal depends on a Drive or GitHub link staying alive.

## Folders

- `photos/` — photos from Google Drive (TEAM PHOTOS + milestone folders), renamed, originals unedited.
- `video-stills/` — frames extracted from the project videos, named with the video's timestamp, e.g. `2026-08-28_IMG8174_0m12s.jpg`.
- `cad/` — Onshape captures from the **Pill Compounder** folder, named with document + version/branch.
- `reference/` — designs and images that are NOT mine (reference models, inspiration). Never filed anywhere else, never captioned as my work.
- `code/` — code versions the journals reference (`app.py`, `motor_scale_controller.py`, Arduino sketches), named with the date that version is from.

## Naming

`YYYY-MM-DD_what-it-is.ext` — the date is the verified date of the thing in the file:

- photo → its EXIF capture date
- video still → the video's QuickTime creation date
- CAD capture → the version's date in Onshape history
- code → the date of that version (email/commit date)

Never the upload, download, or screenshot date. If a capture was made later of an older version, the file name uses the **version's** date and the journal caption says when the capture was taken.

## Provenance

Each journal caption records the source (Drive file name / video name + timestamp / Onshape document + version). The working evidence trail behind the finished log is kept separately and is not part of the published set.
